# 交付前自检清单

按改动类型选对应清单。不要跳过；失败了就说失败，不要用「应该没问题」代替检查。

## 1. 静态稿改动

### 结构与链接

- [ ] 页面在 360×800 下完整呈现，单页只呈现一个状态，没有并排多状态。
- [ ] 没有手机外框、系统状态栏、Home 指示条、设备阴影。
- [ ] 页面内所有本地 `href` / `src` 都能解析到真实文件；没有 `href="#"` 死链。
- [ ] 新增/删除状态时，`index.html` 的入口、计数、`静态稿/README.md` 的状态表三处同步。
- [ ] 在仓库根目录运行 `python -I .claude/skills/campus-run-frontend/scripts/check_static.py` 通过。

### 样式与令牌

- [ ] 颜色、圆角、间距来自 `assets/spec.css`；没有在页面里新写主题色。
- [ ] 卡片是 1px 描边，没有阴影；没有大面积渐变、发光、玻璃拟态。
- [ ] Header 56、TabBar 56、操作栏 68/88、内容边距 16、内容宽 328 与规范一致。
- [ ] 主按钮 52、次按钮 44、输入 48、列表行 56、Chip 视觉 36 / 命中 44、Switch 48×28。
- [ ] 图标是内联 SVG，24 网格、1.75 描边；没有 emoji、图标库、外部图片。

### 内容与行为

- [ ] 文案逐字来自 `UI_SPEC.json` 的 `screens[].copy` / `copyDeck` / `errorHandling`；没有自行改写。
- [ ] 新增文案已标「待确认」，并在回复里说明。
- [ ] 数字用等宽 + `tabular-nums`；配速 `m'ss"/km`、距离 2 位展示 / 1 位输入、时长 `mm:ss`。
- [ ] 状态用「图标 + 文字 + 颜色」三重表达；没有只靠颜色。
- [ ] 四态（loading / empty / error / partial）没有被省略；部分失败说清还能不能继续。
- [ ] 危险动作有确认层和后果说明；运行页取消在 OBS 开始后禁用。
- [ ] 「回查未知」没有显示成「成功」。

### 可访问性

- [ ] 所有触摸目标 ≥ 44×44；视觉小的地方补了命中区。
- [ ] 图标按钮有 `aria-label`；装饰 SVG 有 `aria-hidden="true"`。
- [ ] 图表/轨迹容器有 `role="img"` 和描述性 `aria-label`。
- [ ] 正文对比度 ≥ 4.5:1；弱文字不承载关键结论。
- [ ] 没有依赖 hover 才能触发的操作。

## 2. Vue3 改动（M0 之后）

- [ ] `npm run build` / 类型检查通过；失败时附上错误，不要只写「构建完成」。
- [ ] 路由守卫覆盖 `auth` / `activeRun` / `hasResult`；未登录、无运行、无结果都有落点。
- [ ] 所有桥调用经过 `src/native/protocol.ts`；组件里没有直接碰原生桥。
- [ ] mock 只在开发环境启用，没有进入生产构建。
- [ ] 颜色/圆角/间距使用 `src/styles/tokens.css`；没有组件级硬编码主题色。
- [ ] 每个数据区块有 loading / empty / error / partial 四态；错误映射到规范文案。
- [ ] 没有把原始异常、堆栈、URL、token 展示给用户或写进日志。
- [ ] 固定操作栏避开安全区；主操作在底部 1/3；触摸目标 ≥ 44dp。
- [ ] 数字格式、状态表达、危险动作确认与静态稿一致。
- [ ] 没有新增外部字体、CDN、统计、崩溃上报或未确认的 npm 依赖。

## 3. 文案与规格一致性

- [ ] 改动的按钮/错误/提示文案能在 `UI_SPEC.json` 中找到出处。
- [ ] 没有把「失败」改成更软的词，或把「未知」改成「成功」。
- [ ] 新增字段/状态已同步到规格，或明确标注「待同步」。
- [ ] 人读文档与 JSON 没有明显矛盾；有则已修或已提出。

## 4. 思维链

- [ ] 本次是否产生了决策/里程碑？判断理由是什么。
- [ ] 如果写了：条目包含背景、决定、原因、影响、下一步；位于 `## 记录` 顶部。
- [ ] 如果写了：文件顶部「当前状态」已同步（阶段/已完成/正在进行/下一步/阻塞/最后更新）。
- [ ] 没有重写或删除旧条目；更正用新条目表达。
- [ ] 没有把代码、规格原文成段复制进思维链；用的是路径和字段名。
- [ ] 文件没有超过 200 行 / 30 条；超过了就压缩最老的记录为「阶段摘要」。
- [ ] 最终回复里明确写了「已追加」或「本次无需更新（原因）」。

## 5. 验证报告格式

在回复的「验证」部分写：

```text
跑了：check_static.py（通过：37 个页面，0 断链）
没跑：Vue 构建（app/ 尚未创建）
未覆盖：真机 360×800 截图对比
```

不要只写「已检查」。说清楚检查了什么、结果是什么、没覆盖什么。
